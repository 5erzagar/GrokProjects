1

Python

Mapa

Ollama

Zaženi namestitev in prenos modela:

powershell -ExecutionPolicy Bypass -File .\install_ollama.ps1

Zagon

Odpri aplikacijo:

python main.py

  • Povzemi z Ollama: prilepi besedilo pogovora, klikni Povzemi, pregledaj in Shrani kot novo stanje.
  • Shrani stanje: ročno popraviš trenutno stanje.
  • Komentarji: opombe dodajaš z Enter ali gumbom Dodaj.
